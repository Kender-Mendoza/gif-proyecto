# GifProyecto

Is a web application for search gifts about one topic.
I'm using this project for practice React with typescript.

## Installation

clone de repository:
```bash
git clone git@github.com:Kender-Mendoza/gif-proyecto.git
```
Install dependencies:
```bash
npm install
```
To run the testcases use:
```bash
npx jest
```
